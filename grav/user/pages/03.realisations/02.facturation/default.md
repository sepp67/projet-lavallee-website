Développement d'une application web de facturation électronique sur mesure, pensée pour une petite structure qui voulait garder la main sur ses données de facturation plutôt que de les confier à un service SaaS tiers.

Comme pour mes autres réalisations, l'accent est mis sur un déploiement reproductible, une séparation claire entre le code applicatif et les données de production, et une documentation qui permet de reprendre le projet sans dépendre de moi seul.
